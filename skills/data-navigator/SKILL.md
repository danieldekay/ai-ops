# Data Navigator

Routes to data/science skills in `~/.skills-longtail/academia-science/`. Install for the session, uninstall after.

## Available Skills

| Skill | Use When | Install |
|-------|----------|---------|
| `data-analysis-planner` | Plan full data analysis: environment, phases, scripts — before writing code | `apm install -g danieldekay/ai-ops/skills/data-analysis-planner/` |
| `exploratory-data-analysis` | EDA on scientific files (200+ formats): structure, quality, metrics | `apm install -g danieldekay/ai-ops/skills/exploratory-data-analysis/` |
| `statistical-analysis` | Hypothesis tests, ANOVA, regression, Bayesian, power analysis | `apm install -g danieldekay/ai-ops/skills/statistical-analysis/` |
| `statsmodels` | OLS, GLM, logistic, ARIMA, time series, AIC/BIC diagnostics | `apm install -g danieldekay/ai-ops/skills/statsmodels/` |
| `scientific-visualization` | Publication figures with matplotlib/seaborn/plotly, colorblind-safe, PDF/EPS | `apm install -g danieldekay/ai-ops/skills/scientific-visualization/` |
| `get-available-resources` | Detect CPU/GPU/memory before computationally intensive tasks | `apm install -g danieldekay/ai-ops/skills/get-available-resources/` |
| `scientific-writing` | IMRAD manuscripts, citations, CONSORT/STROBE/PRISMA reporting | `apm install -g danieldekay/ai-ops/skills/scientific-writing/` |
| `scientific-brainstorming` | Research ideation, interdisciplinary connections, methodology exploration | `apm install -g danieldekay/ai-ops/skills/scientific-brainstorming/` |
| `research-grants` | NSF/NIH/DOE/DARPA proposals: significance, innovation, budget | `apm install -g danieldekay/ai-ops/skills/research-grants/` |
| `latex-posters` | Conference posters with beamerposter/tikzposter | `apm install -g danieldekay/ai-ops/skills/latex-posters/` |

## Quick Decision

- Start a data project → `data-analysis-planner` first
- Inspect an unknown data file → `exploratory-data-analysis`
- Run stats tests → `statistical-analysis` (quick) or `statsmodels` (regression/time series)
- Plot results → `scientific-visualization`
- Write up results → `scientific-writing`
- Before intensive compute → `get-available-resources`
