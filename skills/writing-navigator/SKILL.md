# Writing Navigator

Routes to writing skills in `~/.skills-longtail/writing/`. Install for the session, uninstall after.

## Available Skills

| Skill | Use When | Install |
|-------|----------|---------|
| `blog-post` | Long-form blogs, tutorials, educational articles with SEO | `apm install -g danieldekay/ai-ops/skills/blog-post/` |
| `copywriting` | Homepage, landing pages, pricing, feature copy — persuasive and converting | `apm install -g danieldekay/ai-ops/skills/copywriting/` |
| `internal-comms` | Status reports, leadership updates, incident reports, FAQs | `apm install -g danieldekay/ai-ops/skills/internal-comms/` |
| `professional-communication` | Developer email/messaging for technical vs. non-technical audiences | `apm install -g danieldekay/ai-ops/skills/professional-communication/` |
| `communication-storytelling` | Turning analysis/data into narratives for executives or customers | `apm install -g danieldekay/ai-ops/skills/communication-storytelling/` |
| `social-content` | LinkedIn posts, Twitter threads, content calendars, platform optimization | `apm install -g danieldekay/ai-ops/skills/social-content/` |
| `newsletter-generation` | Curated digests, weekly roundups, editorial newsletters | `apm install -g danieldekay/ai-ops/skills/newsletter-generation/` |
| `doc-coauthoring` | Collaborative workflow for specs, proposals, decision docs | `apm install -g danieldekay/ai-ops/skills/doc-coauthoring/` |
| `docx` | Create/edit Word documents with tracked changes and comments | `apm install -g danieldekay/ai-ops/skills/docx/` |
| `markdown-documentation` | READMEs, GitHub Flavored Markdown, documentation formatting | `apm install -g danieldekay/ai-ops/skills/markdown-documentation/` |

## Quick Decision

- Marketing website copy → `copywriting`
- Blog or educational content → `blog-post`
- Email to stakeholders → `internal-comms` or `professional-communication`
- Social posts → `social-content`
- Technical spec document → `doc-coauthoring`
